## PDF_Rename_Expert

Професійний інструмент для автоматизації перейменування відсканованих документів PDF за даними з Excel-бази.

**Інструкція для користувача** (встановлення Python, бібліотек, робота з програмою): [INSTRUKTSIYA_KORYSTUVACHA.md](INSTRUKTSIYA_KORYSTUVACHA.md).

**Розвиток проєкту, процес роботи з актами, відкриті питання та план:** [docs/ROZVYTOK_PROEKTU.md](docs/ROZVYTOK_PROEKTU.md).

### Можливості:
- **Вбудований перегляд**: відображення сторінок PDF у вікні програми.
- **Пошук за EIC** або **технічний облік** (рядки зі стовпцем B = «Технічний» у Excel; у імені PDF — сегмент `технічний-облік`).
- **Підтримка АСКОЕ**: поля IP-адреси та номера модему.
- **Лічильники по підстанціям**: кнопка на панелі відкриває форму редагування книги `Лічильники по підстанціям*.xlsm` (аркуш «база») — аналог VBA-форми з Excel: фільтр за підстанцією, пошук (в т.ч. за останніми 5+ символами EIC / № лічильника), навігація, додавання, збереження й видалення записів, списки з аркуша «Довідники», журнал змін (аркуш «Історія_Змін») і друк картки / усієї підстанції у PDF. Запис іде через Microsoft Excel (потрібні Excel і `pywin32`), тож макроси й форматування книги зберігаються; читання Excel не потребує.
- **Експорт у Excel**: звіти з нумерацією та шириною стовпців.
- **Лічильник символів**: контроль довжини імені файлу.
- **Зручність UI**: прокрутка форми, закріплені кнопки «Обробити» / «Експорт», Ctrl+C/V/X у полях, **F1** — довідка для оператора (`INSTRUKTSIYA_KORYSTUVACHA_APP.md` у exe).

### Структура проєкту (файли коду)
- `pdf_rename_expert.py`: Точка входу (запуск програми та збірка exe).
- `app_ui.py`: Вікно програми та логіка інтерфейсу.
- `naming.py`: Формування й розбір імен PDF, коди полів для експорту.
- `excel_db.py`: Читання Excel-бази споживачів.
- `meters_model.py`, `meters_excel.py`, `meters_form.py`: модель, читання/запис (Excel COM) і вікно форми «Лічильники по підстанціям».
- `Scan\Населення\`: Папка для вхідних PDF (Населення).
- `Scan\Промислові\`: Папка для вхідних PDF (Промислові).
- `pdf_rename_expert.log`: Журнал роботи програми (створюється автоматично).

### ⚠️ ПІДТРИМКА WINDOWS 7 (ВАЖЛИВО)

Щоб програма працювала на Windows 7, ви **ПОВИННІ** використовувати **Python 3.8.10**. Новіші версії Python (3.9+) на Windows 7 не запускаються.

#### Покрокова інструкція для збірки на Windows 7:

1. **Встановлення Python**:
   - Завантажте [Python 3.8.10 (Windows x86-64 executable installer)](https://www.python.org/downloads/release/python-3810/).
   - При встановленні обов'язково поставте галочку **"Add Python 3.8 to PATH"**.
   
2. **Встановлення залежностей**:
   Для звичайного запуску з коду:
   ```bash
   pip install -r requirements.txt
   ```
   Для збірки `.exe` на Win7 використовуйте **`requirements-win7.txt`** (див. `build_win7.bat`).

3. **Компіляція в .exe**:
   ```bash
   pyinstaller --noconfirm PDF_Rename_Expert.spec
   ```
   На **Windows 7** виконайте **`build_win7.bat`** (Python 3.8, venv `.venv-win7`, тести, PyInstaller). Результат: `dist\PDF_Rename_Expert.exe` (файл `rules.json` вшитий у збірку).

4. **Якщо виникають помилки на Windows 7**:
   - Переконайтеся, що встановлені всі оновлення Windows (зокрема **KB2999226**).
   - Встановіть [Microsoft Visual C++ Redistributable](https://aka.ms/vs/16/release/vc_redist.x64.exe).
