# PDF Rename Expert — довідка користувача

Програма перейменовує відскановані PDF у папках **Scan** за даними з Excel-бази споживачів. Нижче — покрокова інструкція для щоденної роботи.

---

## 1. Що потрібно на комп’ютері

У **одній папці** з файлом **PDF_Rename_Expert.exe** мають бути:

| Що | Опис |
|-----|------|
| **PDF_Rename_Expert.exe** | Сама програма |
| **Excel-база** | Книга `.xlsx` (краще назва `Споживачі ЕЕЛ-2 (ЕЧ-2).xlsx`) |
| **Scan\Населення\** | Папка для PDF (населення) |
| **Scan\Промислові\** | Папка для PDF (промислові споживачі) |

Папки **Scan\...** програма може створити сама при першому запуску.

Після роботи поруч можуть з’явитися файли **pdf_rename_expert.log** (журнал) та **pdf_rename_suffix_history.json** (історія поля «Належність лічильника») — їх можна не чіпати.

---

## 2. Якщо програма не запускається

1. Встановіть **Microsoft Visual C++ Redistributable** тієї ж розрядності, що й exe (**x64** або **x86**). Завантажити можна з сайту Microsoft (пошук: *Visual C++ Redistributable latest*).
2. На **Windows 7** переконайтеся, що встановлено **SP1** і оновлення системи (зокрема компоненти для сучасних програм).
3. Запускайте exe **з локального диска**, не з мережевої папки з обмеженими правами.
4. Якщо спрацьовує антивірус — додайте папку програми в виключення або отримайте exe від адміністратора.

---

## 3. Excel-база споживачів

- Книга Excel має містити аркуш **`база`**.
- Якщо файлу з очікуваною назвою немає, програма візьме **перший `.xlsx`** у своїй папці.
- **Не тримайте базу відкритою в Excel** під час пошуку — інакше з’явиться повідомлення, що файл зайнятий.

### Які стовпці використовує програма

| Стовпець | Для чого |
|----------|----------|
| **B** | Позначка **«Технічний»** — абонент без EIC (технічний облік) |
| **T** і **AD** | Назва (у програмі з’єднується як T-AD) |
| **AB** | Повний код EIC (16 символів) |
| **AN** | Адреса |

Кнопка **«Завантажити базу»** перечитує Excel у пам’ять. При старті програми база завантажується автоматично.

## 4. Робота в програмі

### 4.1. Вибір PDF

1. У верхній панелі оберіть **Населення** або **Промислові**.
2. Покладіть PDF у відповідну папку `Scan\...`.
3. Натисніть **«Оновити список (F5)»** — файли з’являться зліва.
4. Клацніть по файлу — у центрі буде **перегляд** сторінок PDF.

### 4.2. Пошук споживача в базі

#### Звичайний облік (є EIC)

1. Прапорець **«Технічний облік»** має бути **вимкнений**.
2. У полі **EIC (останні 5+ символів)** введіть **не менше 5 символів** з кінця EIC.
3. У **«Збігах»** оберіть потрібний рядок.
4. Заповняться **Назва**, **Адреса** та **повний EIC** (за потреби відредагуйте).

#### Технічний облік (без EIC)

1. Увімкніть **«Технічний облік»** — поля EIC стануть неактивними.
2. У **випадаючому списку «Збіги»** оберіть абонента (рядок: **код T — назва — адреса**).
3. Заповняться **Назва** та **Адреса**.
4. У **імені PDF** замість EIC буде напис **`технічний-облік`**.

### 4.3. Дані документа

Заповніть **дату**, **№ лічильника**, **фазу**, **вид роботи**, **вид перевірки**. За потреби — **Інвест**, **належність лічильника**.

Якщо обрано роботу з **АСКОЕ**, з’являться поля **IP-адреса** та **№ модему**.

У блоці **«Ім’я PDF (прев’ю)»** показано майбутнє ім’я файлу та його довжину. Кнопка **«Копіювати»** — скопіювати ім’я в буфер.

### 4.4. Перейменування файлу

1. Оберіть PDF у списку зліва.
2. Перевірте прев’ю імені та **рядок статусу** внизу (там будуть попередження про помилки).
3. Натисніть **«Обробити»** або **Ctrl+Enter**.

Файл перейменовується **у тій самій папці**. Якщо таке ім’я вже є, додасться суфікс **(1)**, **(2)** тощо.

### 4.5. Звіт у Excel

**«Експорт в Excel»** — звіт по вже перейменованих PDF у папках Scan. Файл зберігається у папці програми; якщо звіт уже існує, програма запитає про перезапис.

---

## 5. Корисні клавіші

| Дія | Клавіші |
|-----|---------|
| Ця довідка | **F1** |
| Оновити список PDF | **F5** |
| Обробити (перейменувати) | **Ctrl+Enter** |
| Копіювати / вставити / вирізати в полях | **Ctrl+C**, **Ctrl+V**, **Ctrl+X** |
| Виділити все в полі | **Ctrl+A** |
| Копіювати рядок у списку PDF | **Ctrl+C** |

Праву частину вікна (форма) можна **прокручувати коліщатком**; кнопки **«Експорт»** та **«Обробити»** завжди внизу.

---

## 6. Типові питання

| Що сталося | Що зробити |
|------------|------------|
| «Не знайдено Excel-базу» | Покладіть файл `.xlsx` у папку з exe; перевірте аркуш **база**. |
| «Файл Excel зайнятий» | Закрийте книгу в Excel. |
| Не видно PDF у перегляді | Перевірте, що файл не пошкоджений; спробуйте відкрити його звичайним переглядачем PDF. |
| Довго «крутиться» завантаження бази | Зачекайте; не відкривайте той самий xlsx у Excel. |
| Порожні «Збіги» в техобліку | У стовпці **B** має бути **Технічний**; натисніть **«Завантажити базу»**. |
| Помилка про EIC | Для звичайного обліку — повний EIC 16 символів; для техобліку — увімкніть прапорець і оберіть рядок у «Збігах». |
| Не видно кнопку «Обробити» | Зменште масштаб вікна або прокрутіть форму вправо вниз — кнопка закріплена внизу панелі. |

---

## 7. Звернення до адміністратора

Якщо потрібна нова версія програми, оновлення бази Excel або права доступу до папок — зверніться до **відповідального за IT** у вашій установі.

Повну технічну документацію (встановлення Python, збірка exe) зберігають адміністратори окремо від цієї довідки.
